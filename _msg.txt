fix(tools): make the dev launcher work on a non-UTF-8 console code page

The first version of start-dev.cmd never started anything. Two causes:

- it was UTF-8 with Chinese text plus a chcp 65001 line. cmd re-reads a batch
  file as it executes, and the code-page switch shifts its byte offsets, so
  lines were parsed incorrectly. The launcher is ASCII-only now.
- the delayed browser open used a nested-quote start line, which cmd parses
  unreliably. It now goes through powershell with single-quoted literals.

Verified by running it: web 200, api 200 with database up, both ports
listening, console window opens with the expected title and the browser
follows automatically.
