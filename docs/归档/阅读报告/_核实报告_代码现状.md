### 1.2 `pnpm typecheck` / `pnpm -r test` / `pnpm check:build` 各自会跑什么

根 `package.json:12-29` 的 scripts：

| 命令 | 根定义 | 实际会跑什么 | 证据 |
|---|---|---|---|
| `pnpm typecheck` | `"typecheck": "pnpm -r typecheck"` | 在**每个 workspace 包**里跑它的 `typecheck` script → 三个包各有 `tsc --noEmit` | `package.json:17`；`packages/shared/package.json`（`"typecheck": "tsc --noEmit"`）、`apps/web/package.json`、`apps/api/package.json` 同 |
| `pnpm -r test`（根 `pnpm test`） | `"test": "pnpm -r test"` | 三个包各跑 `vitest run`；web 只收 `src/**/*.test.ts(x)`（node 环境），api 只收 `test/**/*.test.ts` 且 `fileParallelism: false`（共用一个 PostgreSQL） | `package.json:19`；`apps/web/vitest.config.ts:14-17`；`apps/api/vitest.config.ts:3-10`；`packages/shared/package.json`（`"test": "vitest run"`，**无 vitest 配置文件**，走默认） |
| `pnpm check:build` | `"check:build": "node tools/check-build.mjs"` | 跑 `pnpm --filter @libellum/web build`，即 web 的 **`tsc --noEmit && vite build`**（真实构建，会编 CSS） | `package.json:18`；`tools/check-build.mjs:24-28`；`apps/web/package.json` 的 `"build": "tsc --noEmit && vite build"` |

**`tools/check-build.mjs` 存在的理由（原文）**：`check:build` 是在"`@theme` 里写了一条普通 CSS 规则把整个应用搞挂、
而 typecheck 与 test 全过"之后写的（`tools/check-build.mjs:1-14`），
所以它**只对 web 跑真实构建，不跑 api 的构建**（`tools/check-build.mjs:24`：`["--filter", "@libellum/web", "build"]`）。

**⚠️ 三个命令的范围差异（重要）**：
- `typecheck` 覆盖 **shared + web + api** 三包 → 类型层面全覆盖。
- `pnpm -r test` 覆盖 **shared + web + api** 三包，但**不覆盖 `apps/ocr` / `apps/voice`**（这两个是 Python，不是 workspace 包）。
- `check:build` **只覆盖 web**（`apps/api` 没有 `build` script；`package.json:16` 的 `pnpm -r build` 也只会跑到 web 的那一个）。

### 3.2 ★ 重点：`judge()` 的签名里确实没有版本号参数

**✅ 文档说法成立，而且函数里还写着为什么。**

**定义位置**：`apps/api/src/lib/conflicts.ts:155-191`（**在服务端，不在 web 的离线层**）。

```ts

  field: ConflictField,
  /** The device's starting value — the owner calls it a 历史值. */
  base: unknown,
  /** What the device wants the field to become. */
  wanted: unknown,
  /** What the server holds right now. */
  serverValue: unknown,
  /**
   * Every value the server has held, **including the one it holds now** (`valuesSeen` appends it).
   */
  history: readonly unknown[] = [],

```

**签名参数共 4 个（+1 个默认值）：`field` / `base` / `wanted` / `serverValue` / `history`。
没有 `baseVersion`，没有 `serverVersion`。**

**代码里明写了这是刻意的**（`conflicts.ts:118-121`）：

> ⚠️ **There is no version number in here, and that is deliberate.** An earlier version opened with
> `baseVersion >= serverVersion → accept`, and the owner had already rejected version numbers as the basis for this
> decision — **the idea survived inside the code and quietly disabled the whole feature** …

**四条判定规则**（`conflicts.ts:172-190`）与文档 `docs/交接.md:166-169` 的表格逐条一致：
`base == serverValue` → `accept`(:172)；`wanted == serverValue` → `server-wins`(:178)；
`wanted ∈ history` → `server-wins`(:184)；否则 → `conflict`(:190)。
