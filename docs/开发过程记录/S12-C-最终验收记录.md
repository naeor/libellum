## 二、真实验收中发现并修复的问题

1. **COS 403 真正根因 = `PathStyleDomainForbidden`**：rclone 对非 AWS 端点默认 path-style，COS 要求虚拟主机风格 → 加 `force_path_style=false`（`9e745df`）
2. 异地恢复三处 bug：`lsf` 需 `-R`；`--latest` 漏 `daily/` 前缀；对照解析误把数字字段当表名（`110feab`）
3. 邮件发件域必须是 `send.libevra.com`（与已验证域一致）
4. PowerShell 5.1 的 UTF8 写入带 BOM → `source` 失败、systemd 首行被判为赋值；统一改为无 BOM/ASCII（`2014c86`）
5. **安全事件**：一次 `bash -x` 把 `source` 的 COS 密钥打到输出 → 已轮换两个身份密钥，并记录教训 §8.14
