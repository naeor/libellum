# 海浪效果要求与实现交接

更新：2026-10-13，版本 1.09.72。适用页面：`/start`。

## 文档的使用方式

产品目标、可见效果与交互行为是验收依据。算法、公式、布局方式与参数是可替换的实现选择，不是唯一技术方案。历史问题的原因必须结合当时代码理解；本文件不再把推测写成通用定律。未来接手时仍需检查实际代码与浏览器画面。

## 状态术语

本文的「展示态」是尚未上滑的品牌海浪画面（p=0，旧文档也称海浪展开态）；「列表态 / 顶部栏」是上滑进入账本后（p=1，旧文档称海浪收缩态）。用户本轮所说的「展开态」指账本内容展开，应按列表态理解。

2026-10-13 本轮补充：展示态应更舒缓、错落；上滑中逐渐收敛；列表态顶部安静，可以接近水平，不为消除平行感强行增加起伏。箭头改向上，文案改为「上滑，进入我的账本」。

## 产品要求

- 账本空间是同一页面的展开、收缩两种形态；海浪始终横跨全宽、保留在顶部。
- 展开态海浪代表高度约为可视高度 80%；收缩态约 15%。短横屏及设备安全区可为品牌可读性适当增加高度。
- 四层由深到浅：`#3f7059`、`#4f8a6d`、`#6aa78a`、`#96c4ac`。展示构图约 70/10/10/10；列表态遵循本轮「安静顶部栏」目标，适当收窄浅色区域（当前约 74.5/8.5/8.5/8.5，替代上一轮 61/13/13/13）。这是代表性高度关系，不要求所有横向位置等高。
- 三个过渡层在运动与切换中保持海浪代表高度约 5%–15% 的可见厚度，不消失、不交叉、不变成大色块。
- 波面柔和、舒展、连续；各层相互呼应但不完全复制。可以共享整体潮汐，再叠加细节差异。
- 展开态静置数秒能看出克制的流动；收缩态减弱。品牌不随潮汐晃动。
- 顶部始终深色覆盖，无浅色漏底、空白、矩形边缘或裁平的波面。
- 海浪收束与内容上移同时发生，反向展开时内容同步让出空间。只保留一套真实列表和一套连续移动的品牌，不用交叉淡化拼状态。
- 手势跟手，松手按位置和速度自然吸附。只有列表在顶部继续下拉才展开，普通列表滚动不误触发。
- 正文进入顶部区域后正确裁切，不能越过海浪出现在其上方。
- 展示态底部只有向上箭头和「上滑，进入我的账本」提示，不露真实卡片；提示可点击，以支持鼠标和键盘。
- 品牌展开时居中，收缩时连续移到左上；字号与顶部距离参考 1.4rem / 14px，并考虑安全区。
- 首次可展开、后续默认收缩；保持恢复上次账本的既有逻辑。
- 手机、iPad、桌面及横竖屏适配；减少动态效果时保留结构、停止环境波动并简化吸附。
- 保留创建、进入、分享、邀请、管理、同步等业务。不得为海浪修改无关后台或权限。
- 名称遵循最新项目决定。本次检索源码和文档未发现 Libevra 的采用记录，因此保留当前 Libellum；不能据此阻止未来正式更名。

进度 `p=0` 展开、`p=1` 收缩。海浪在正常布局中占据实际高度，下方提示区域从 20dvh 连续压缩到 0，余下空间成为同一列表的滚动窗口。列表窗口自身裁切正文，SVG 在海浪盒子下方保留曲线余量，不旋转、不整层缩放、不额外放大图形。顶部路径闭合在视口外，始终深色覆盖。

代表高度为 `80dvh → max(15dvh, 116px + safe-area-inset-top × 1.7)`。短横屏的 15% 容不下品牌与标语，因而使用可读性下限；层次比例始终以实际海浪高度计算。标准手机竖屏仍为约 15%。品牌字号 2.1rem → 1.4rem，收缩顶距 14px + 安全区，左距 20px + 安全区。

本轮仅局部调整 `oceanGeometry.ts` 与提示箭头/文字。保留 SVG 三次曲线、页面布局、配色和手势机制。降低共享波形的振幅和整体倾斜，增加各层有界曲线的相位、波长与缓慢节奏差异，没有随机噪声。

以 `s=p²(3−2p)` 平滑收敛，边界为 `0.70 + 0.045s + layer × (0.10 − 0.015s) + shared + detail`。detail 的幅度从 0.022 降到 0.003，各层相同的 shared 在相邻差值中抵消。因此任一带宽下界为 `0.056 + 0.023s`，上界为 `0.144 − 0.053s`，全程仍在 5%–15% 内。展示态峰谷与层间宽度更错落；列表态减少浅色带面积、曲率与动态，不把明显波浪强行带入顶栏。公式与参数是当前选择，不是唯一方案。

环境动画连续推进时间，不按固定周期强制重置。页面隐藏时暂停，返回时不补跑隐藏时段；减少动态时停止环境动画，拖动仍更新曲线，松手直接到目标态。品牌只读取进度，不读取潮汐时间。

手势锁定开始时的列表顶部条件，有 8px 方向阈值，横向滑动和输入框不抢占。从列表中部开始的向下滚动始终属于列表，需到顶后重新下拉。滚轮在收缩态向下滚动正常交给列表。修正了此前滚轮释放方向以及触摸速度到进度速度的符号；未修改共用物理函数。触摸中断、横向放弃与 resize 会恢复吸附。展开时内容区 inert，避免键盘焦点进入屏外列表。

## 被替换的旧假设与历史经验

- 旧文档将各层独立摆动当成必要条件，导致难以同时满足厚度与动态。共享运动允许明显起伏，并不必然让曲线平行。
- “振幅只能 1.5–2vh”“唯一办法是拉开层间距离”只适用于特定的独立振幅最坏估计；不适用于共享位移在差值中抵消的情况。
- 固定曲线的纯缩放确实不能改变端点比例，但路径形变可以；没有两套路径交叉淡化的必要。
- “至少 120 个点才能柔和”不是通用结论。三次曲线可以用更少的段数获得连续切线。
- `scaleY`、固定定位、旋转三度、CSS 变量均非产品要求。本次保留变量驱动布局，但替换了独立缩放及旋转。
- Tailwind、CSS 作用域、错误滚动引用曾是具体故障，应看当时产物。不能将所有静止、平直或卡顿都归因于同一个原因。
- 仍有价值的检查：顶部覆盖、曲线裁切、全文是否混入注释、SVG 显式宽高、内容是否同步移动、滚动归属是否读取真实 scroller。编译成功不能替代视觉检查。
