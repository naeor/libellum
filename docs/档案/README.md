## ⚠️ 两条注意

### 1. `.docx` 在**上一层**，不在这里

**Markdown 是源文件，`.docx` / `.pdf` 是生成物。**
**生成物统一放在 `docs/` 根目录**——因为文档构建脚本的导出名一直是这样，
**改导出名会让所有已有的下载链接和打印习惯失效。**

所以：
- **改内容** → 改这里的 `.md`；
- **看阅读版** → 去 `docs/` 找同名 `.docx`；
- **⚠️ 而 `pnpm docs:build` 会重新生成上一层的 `.docx`，覆盖手工改动。**

### 2. 为什么它们被移到这里

**所有者的原话**：

> **"新建一个不常用文件夹，把所有现在用不到的文件放进去。"**

**而他举的例子是"S8 的设计决定"**——
**而 S8 第 3 轮（冲突）刚刚做完，所以那几份确实不需要天天翻了。**

**⚠️ 而"刚做完"不等于"不用读"**：
**S8 第 4 轮（离线拍照排队）已由所有者取消（2026-10-11）**，所以那条"必读"的时机**不会再到来**；
**但只要有人再改离线的新建 / 修改 / 删除（那是明细页与详情页的日常路径），
`S8-离线写入-设计决定.md` 仍然是必读的。**
