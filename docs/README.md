## 📱 手机访问（含**必须的**一次性证书信任）

手机连同一个 Wi-Fi 后，地址是 **`https://192.168.0.184:5173`** —— **是 https，不是 http**。

### ⚠️ 为什么必须是 https

`getUserMedia`（录音）、`MediaRecorder`、`crypto.randomUUID`、Service Worker
**全都是"安全上下文"API**：浏览器**只在 https 或 localhost 上才定义它们**。

用 `http://192.168.0.184:5173` 打开时，页面看起来一切正常，但：

| 现象 | 真相 |
|---|---|
| 录音页说**"这个地址不是安全连接"** | 浏览器**根本没定义** `mediaDevices`。**不会弹权限提示——因为没有 API 可以提示** |
| `crypto.randomUUID is not a function` | 同一个原因（**这个坑踩过一次**） |
| 离线（Service Worker）不可用 | 同一个原因 |

> **这两个坑各浪费过一次排查时间，原因完全相同：URL 不是安全上下文，而提示说的是浏览器。**

### 一次性准备

```bash
pnpm dev:cert   # 生成开发用证书（自签，自动覆盖 localhost 与本机所有局域网 IP）
pnpm dev:lan    # 以 https 启动，监听 0.0.0.0
```

> ⚠️ **换了 Wi-Fi、或路由器重分了 IP 之后要重跑 `pnpm dev:cert`**——
> 证书里写着具体 IP，地址变了证书就对不上了。

### 手机上信任证书（**只做一次**）

自签证书浏览器不认，会拦一下。**这不是出错，是自签证书的正常表现。**

**iPhone / Safari**

| 步 | 做法 |
|---|---|
| 1 | Safari 打开 `https://192.168.0.184:5173` → 显示"此连接非私人连接" |
| 2 | 点 **「显示详细信息」→「访问此网站」**。页面能开了，但**录音仍然不可用**——还差第 3 步 |
| 3 | **设置 → 通用 → VPN 与设备管理** → 找到 **Libellum local development** → **安装** |
| 4 | **设置 → 通用 → 关于本机 → 证书信任设置** → 打开 **Libellum local development** 的开关 |
| 5 | 回 Safari 刷新 → 录音可用 |

> ⚠️ **第 4 步最容易漏。** 装完证书**不打开信任开关**，Safari 依然认为它不可信，
> 而且界面不会告诉你差在哪——症状和第 2 步之后一模一样。

**Android / Chrome**

| 步 | 做法 |
|---|---|
| 1 | Chrome 打开地址 →「高级」→「继续前往」 |
| 2 | **设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书**，选下载好的证书 |
| 3 | 刷新页面 |

> 证书文件在 `apps/web/.certs/dev-cert.pem`（私钥同目录，已在 `.gitignore` 里——
> **私钥不进仓库，哪怕是自签的**）。

## 🔄 怎么重新生成 Word / PDF

Markdown 改完之后，运行：

```
pnpm.cmd docs
```

（或让 AI 助手重新生成。生成脚本在 `tools/md2docx.py`。）

> **PDF/DOCX 不进 Git 仓库**（见 `.gitignore`）——它们是导出件，随时可从 Markdown 重新生成。
> 如果你希望简历里直接能点开 PDF，把 `.gitignore` 里那两行删掉即可。

## 🚨 排查任何"页面行为不对"的第一步：**重启 dev server**

**2026-10-09 的教训。** 项目所有者在 iPhone 上点「拍照」时，
**每次都会回到明细页**。我依次怀疑并**排除了**：iOS 文件选择器、路由未注册、
路由未匹配、打包漏文件、Service Worker 缓存、导航逻辑——**六个假设全错**。

**真正的原因**：dev server 已连续运行数小时，**Vite 一直在提供陈旧（stale）的模块**。
磁盘上的 `BottomNav.tsx` 是正确的，但浏览器收到的是几小时前的版本。

**决定性证据**（这条命令应该第一个跑）：

```powershell
# 看 Vite「实际吐出」的模块，和磁盘上的对不对得上
(Invoke-WebRequest "http://localhost:5173/src/components/<组件>.tsx" -UseBasicParsing).Content |
  Select-String "关键 import"
```

当时的结果：模块里**用了 `Link`，却没有任何 `react-router` 的 import** →
`Link is not defined` → 全站崩溃。

**为什么会陈旧**：我分两步编辑同一个文件（先加用法、后加 import），
**中间那几秒 Vite 把一个坏模块推给了所有客户端，而它一直没被刷新掉。**

### 正确流程

| 步骤 | 命令 |
|---|---|
| 1. 停 | `Get-Process node \| Stop-Process -Force` |
| 2. **清 Vite 缓存（关键，别省）** | 删掉 `apps/web/node_modules/.vite` |
| 3. 启 | 双击 `docs\启动记账服务器.lnk`（从资源管理器启动进程才能存活） |
| 4. 验证 | 抓一次模块内容，确认改动在里面 |

> **推论：编辑一个文件时，尽量一次改完。** 分步编辑会制造出中间态的坏模块，
> 而 HMR 可能把它留在客户端上。

> **另一个推论：任何"手机上不对、电脑上对"的现象，先怀疑 dev server，再怀疑设备。**

## 🎫 生成邀请码

注册需要邀请码（项目开源但**不开放注册**）。两种方式：

| 方式 | 怎么做 | 适合 |
|---|---|---|
| **双击** | `docs\生成邀请码.cmd` | 最省事，窗口里会打印一串形如 `ABCD-EFGH-JKMN` 的邀请码 |
| **批量** | `pnpm invite:batch 98 --note "首批"` | 一次生成一批，一个事务，编号连续 |

> **每个码**会**预留账号编号**（生成时就定好，不是注册时才决定），用它的账号会拿到那个编号。
> 首批预留区间是 `10000002–10000099`，这些账号**是管理员**（能看全部数据、含弃置账本）。
> 之后的码从 `10000101` 起依次分配。
>
> ⚠️ **邀请码是明文保存的**（它需要能被念给家人听），所以**清单就是凭据**：
> 不要贴到任何公开的地方，也不要在 `.md` 里引用真实邀请码（这条踩过坑，见 DEVLOG §1.32）。

## 👥 造一个测试账号和一批数据

想让家人试用、或想自己试某个界面，可以造一个带真实数据的账号：

```bash
node tools/seed-test-account.mjs --user mama --password "mama-password-2026" --display "妈妈"
```

它会**通过 HTTP 接口**（和你用浏览器完全一样）做完这些事：

| 步 | 说明 |
|---|---|
| 1 | 自动生成一个邀请码并注册账号（账号已存在就直接登录，**不会重复创建**） |
| 2 | 建账本、预设分类、支付方式（注册时自动完成） |
| 3 | 新建 4 个标签：可报销 / 出差 / 大件 / 家庭 |
| 4 | 写入约 3 个月、118 笔账：日常消费、房租水电、工资、退款、理财；含人民币 / 美元 / 港币；**留 1 笔已删除的（墓碑）** 用来试"恢复" |
| 5 | 打印用户名、密码、昵称、账号编号，以及本月的支出 / 收入汇总 |

> **它故意不做的事**：**不会重复灌数据**——账号里已经有账目时，它会停下并告诉你（真想追加请加 `--more`）；
> **不写数据库、只走接口**——直连数据库会跳过校验、分类规则和幂等逻辑，那样造出来的数据证明不了任何事。
>
> 想给别的账号造数据，换 `--user` / `--password` / `--display` 即可。

## 🔑 忘记密码怎么办（恢复码）

**恢复码是唯一能自助找回密码的东西**，注册时只显示一次。

| 情况 | 做法 |
|---|---|
| 记得密码 | 登录后到「账户 → 设置 → 重新生成恢复码」，**新的生成后旧的立刻失效** |
| 忘了密码、**有恢复码** | 登录页 →「忘记密码」→ 填用户名 + 恢复码 → 设新密码。**恢复码只能用一次** |
| 忘了密码、**恢复码也丢了** | 只能由我直接改数据库（本地开发库），或重新注册一个账号 |

> ⚠️ **恢复码是明文，别放进 Git。** 仓库的 `docs/*.docx` 已被 `.gitignore` 排除，
> 但如果把恢复码写进任何 `.md` 或聊天里发给别人，它就等于公开了。
